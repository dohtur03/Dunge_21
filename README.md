# ROGUE 1980 (REMAKE) – TUI Main Menu

Курсорное меню на `curses` с анимированным логотипом, крупными ASCII‑заголовками и несколькими подменю: новая игра, загрузка, таблица очков, настройки и выход.

## Запуск
python3 main.py

Требования:

- Python 3.10+
- Терминал с поддержкой `curses` и цветов

`main.py`:

- Создаёт окно `stdscr` через `curses.wrapper`.
- Инициализирует `Menu(stdscr)`.
- Вызывает `menu.run()` и завершает приложение после выхода из меню.

## Структура проекта

- `main.py` — точка входа, создание и запуск меню.
- `draw.py` — все функции отрисовки и ASCII‑арт:
  - `logo` — большой логотип ROGUE.
  - `big_start`, `big_load_game`, `big_score`, `big_settings`, `big_exit`, `big_yes`, `big_no` — крупные надписи для выбранных пунктов и подменю.
  - `options` — список пунктов главного меню.
  - `draw_logo(stdscr, y_offset)` — рисует логотип по центру сверху.
  - `draw_menu(stdscr, first_line_y, selected, blink)` — рисует один кадр главного меню:
    - подсвеченный пункт с указателем `▶` и псевдо‑тенью;
    - крупный ASCII‑заголовок под логотипом в зависимости от выбранного пункта;
    - подсказку `<Press '↑/↓' to choose any option, 'Enter' to select>`;
    - версию игры, блок `made by` и список ников снизу экрана.
  - `animate_logo(stdscr, y_offset)` — поочерёдная отрисовка строк логотипа с задержкой (анимация при старте).

- `menu.py` — логика главного меню и всех подменю:
  - класс `Menu`:
    - инициализация цветов и состояния (`self.sound_on`);
    - `run()` — главный цикл;
    - `load_game()` — меню загрузки слотов;
    - `score_menu()` — меню счёта;
    - `settings_menu()` — меню настроек;
    - `exit_menu()` — меню подтверждения выхода.

## Главное меню (`Menu.run`)

После запуска:

1. Окно очищается.
2. Логотип анимируется один раз (`animate_logo`), затем статично рисуется (`draw_logo`).
3. Высчитывается вертикальный центр для блока меню, логотип остаётся закреплённым сверху.
4. Запускается бесконечный цикл:
   - экран очищается;
   - сверху рисуется логотип;
   - под ним — кадр меню через `draw_menu`:
     - пункты:
       1. `Start new game`
       2. `Load game`
       3. `Score`
       4. `Settings`
       5. `Exit`
     - выделенный пункт мигает между двумя цветами, рисуется жирным с указателем `▶` и тенью;
     - под пунктами — подсказка по управлению;
     - под логотипом — крупный ASCII‑арт в зависимости от выбранного пункта;
     - внизу — версия, `made by`, и никнеймы в разных цветах.
   - обрабатывается ввод:
     - `↑/↓` — смена выделенного пункта (`selected`) по кругу;
     - `Enter` — действие по текущему пункту;
     - внутренний флаг `blink` переключается каждые 300 мс для эффекта мигания.

### Действия пунктов главного меню

1. **Start new game**

   - Очищает экран.
   - Печатает в центре:
     ```
     The adventure begins. So may God have mercy on your soul, <player_name>!
     ```
   - Ждёт клавишу и завершает `run`, возвращая `None`.

2. **Load game**

   - Вызывает `self.load_game()`.
   - Если метод вернул имя слота (`"test_slot"`), показывает экран:
     ```
     Loading slot <test_slot>!
     ```
   - Ждёт клавишу и завершает `run`.

3. **Score**

   - Вызывает `self.score_menu()` и после возврата просто перерисовывает главное меню (без повторной анимации логотипа).

4. **Settings**

   - Вызывает `self.settings_menu()` и после возврата продолжает работу главного меню.

5. **Exit**

   - Вызывает `self.exit_menu()`.
   - Если пользователь подтвердил выход — показывает финальное сообщение:
     ```
     Good luck! See you next time!
     ```
     затем ждёт клавишу и завершает `run`.
   - Если выбрано «No» — возвращается к главному меню без повторной анимации логотипа.

## Меню загрузки (`load_game`)

`load_game()` рисует экран выбора слота:

- Сверху — крупный ASCII‑заголовок `big_load_game`.
- По центру — список слотов:

  - 1‑й: `<test_slot>`
  - 2–10‑й: `<empty>`
  - 11‑й: `Back`

- Управление:
  - `↑/↓` — перемещение выделения по списку.
  - Выделенный слот мигает, отмечен `▶`.
  - `Enter`:
    - если выбран `Back` — метод возвращает `None` (возврат в главное меню);
    - если выбран `<empty>` — ничего не происходит (выбор игнорируется);
    - если выбран `<test_slot>` — метод возвращает `"test_slot"` (без угловых скобок), что используется в `run` для сообщения `Loading slot <test_slot>!`.

## Меню счёта (`score_menu`)

`score_menu()`:

- Сверху по центру — крупный ASCII‑заголовок `big_score`.
- В центре экрана один пункт `Back`:
  - выделяется стрелкой `▶`, мигает и рисуется жирным;
- Управление:
  - `↑/↓` — формально переключают `selected`, но с одной опцией он остаётся 0;
  - `Enter` — возвращает в главное меню.

## Меню настроек (`settings_menu`)

`settings_menu()`:

- Сверху по центру — ASCII‑заголовок `big_settings`.
- В центре — два пункта:

  1. `Sound: ON/OFF`
  2. `Back`

- Управление:
  - `↑/↓` — переключение между `Sound` и `Back`, текущий пункт подсвечен и мигает.
  - `Enter`:
    - если выбран `Sound` — переключает `self.sound_on` между `True/False` и обновляет текст `Sound: ON/OFF`;
    - если выбран `Back` — возвращает в главное меню.

## Меню выхода (`exit_menu`)

`exit_menu()` показывает окно подтверждения выхода:

- В верхней части — большой ASCII‑текст:
  - `big_yes`, если выбран вариант `Yes`,
  - `big_no`, если выбран `No`.
- Ниже — вопрос:

Are you sure you want to leave the game?

- Под вопросом — список из двух опций:

1. `Yes`
2. `No`

Выделенная опция указана `▶`, мигает и рисуется жирным.

- Управление:
- `↑/↓` — переключение между `Yes` и `No`.
- `Enter`:
  - возвращает `True`, если выбран `Yes`;
  - возвращает `False`, если выбран `No`.

`Menu.run()` использует возвращаемое значение, чтобы либо выйти из программы с финальным сообщением, либо вернуться в главное меню.

## Особенности реализации

- Весь рендеринг вынесен в `draw.py`, логика и обработка ввода — в `menu.py`.
- Логотип анимируется только один раз при запуске приложения.
- Все подменю (`load_game`, `score_menu`, `settings_menu`, `exit_menu`) возвращают управление в `run` без повторной анимации.
- Внизу каждого кадра главного меню отображается версия игры и список авторов / студентов, выровненный по центру и раскрашенный различными цветами.
